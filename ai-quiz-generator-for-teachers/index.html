Create a quick video-based check

Choose a YouTube lesson, paste its link into Video Quiz, and select the quiz length. The AI prepares multiple-choice questions based on the video so learners can check their understanding after watching.

Use existing study materials

Teachers and learners can also select supported PDFs, text files, and images. This makes it possible to create a practice quiz from notes, handouts, or photographed study material.

Use explanations to guide review

Each answer includes an explanation. Learners can retry after an incorrect choice, and missed questions return in a review round. Treat generated questions as a starting point and review them before using them for formal assessment.

Frequently asked questions

Can teachers use generated quizzes for graded exams?

Generated questions should be reviewed by the teacher before any formal or high-stakes assessment.

What source materials can be used?

The app accepts YouTube video links and supported PDF, TXT, and image files within the limits shown in the app.

Does it support self-study too?

Yes. Students and independent learners can use the same workflow to review lessons and practice.
